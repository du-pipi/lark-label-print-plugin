# 飞书多维表格 - 商品标签自定义排版打印插件（v0.2）

基于 React + TypeScript + Vite 的飞书多维表格**边栏插件**，用于商品标签的自定义排版与浏览器打印。
**已接入真实飞书 SDK、真实条码/二维码、一页一个 60×40 标签。**

## ✨ 功能特性（已落地）

- **真实数据接入**：通过 `@lark-base-open/js-sdk` 读取当前多维表格的字段与记录，字段列表**动态生成**，用户在左侧面板自选/拖拽，不写死。
- **真实条码 / 二维码**：用 `jsbarcode`（CODE128）+ `qrcode` 在浏览器本地生成，**不把数据发往任何外部服务**（符合飞书数据安全红线）。
- **一页一个标签**：默认预设「单张 60×40mm 一页一个」，也保留多张网格预设（一页多标签）。
- **字段拖拽排版**：拖字段到画布 / 双击添加；画布内自由拖动、缩放。
- **精细样式**：字体/字号/颜色/加粗斜体/对齐/行高/边框/背景/圆角/内边距；图片填充方式。
- **静态文本**：可加非字段文本（如"价格："前缀）。
- **多记录预览**：顶部切换记录看不同商品效果；飞书内选中记录自动联动。
- **浏览器打印**：一键打印 / 导出 PDF；打印时按标签实际尺寸出纸（`@page` 动态 size）。
- **布局持久化**：排版元素与标签尺寸存 `localStorage`，重开不丢。

## 🛠️ 技术栈

- React 18 + TypeScript + Vite 5
- `@lark-base-open/js-sdk`（飞书多维表格官方 SDK）
- `jsbarcode` + `qrcode`（本地条码/二维码）
- CSS `@media print`（打印样式）

## 🚀 本地运行 / 开发

```bash
npm install
npm run dev      # http://localhost:5173 （未嵌入飞书时显示"演示数据"，功能可完整体验）
npm run build    # 产物在 dist/，已设 base:'./' + package.json "output":"dist"，符合飞书托管规范
```

> 本地浏览器直接打开是**演示模式**（用内置 mock 数据），用于验证 UI 与排版；真正读你的表格数据必须在飞书内打开。

## 🔌 在飞书多维表格中使用（自定义插件，无需创建应用/审核）

> 边栏插件的门槛就是"一个可访问的网页地址"，不需要走"创建飞书应用 + App ID + 审核发布"流程。

1. **部署插件网页**（二选一）：
   - 本地调试：保持 `npm run dev` 运行，`http://localhost:5173` 即运行地址（仅本机能用）。
   - 公网/共享：把 `dist/` 部署到 GitHub Pages / Vercel 等 HTTPS 地址（全公司可用）。
2. **在多维表格添加插件**：
   - 打开任意多维表格 → 右上角「插件」→「自定义插件」→「+ 新增插件」→ 填入上面的运行地址 → 确定。
3. **使用**：插件在右侧边栏打开，自动读取当前表的字段；拖字段排版 → 顶部「🖨️ 打印」。

## 📖 使用要点

- **字段自选**：左侧字段面板由当前表结构动态生成，拖到画布即绑定。附件字段默认当"图片"渲染，选中后可在右侧属性面板手动切换成"条码/二维码"。
- **标签尺寸**：顶部「⚙️ 标签设置」选预设或自定义宽高、行列、边距。默认 60×40 一页一个。
- **一页多个 vs 一个**：预设里"多张 60×40（一页 3×7）"用于普通纸批量打；单张预设用于 60×40 标签打印机。
- **打印设置**：浏览器打印对话框里把"边距"设为"无"，缩放 100%，才能精确匹配标签纸。

```
src/

  components/

    FieldPanel.tsx        # 左侧动态字段面板

    LabelItemView.tsx     # 标签元素（渲染）

```

## ⚠️ 注意事项

1. 飞书字段类型映射见 `src/feishu/sdk.ts`：`mapFeishuType()`。附件→图片，数字/电话→number，日期→date，单选/多选→select，其余→text。
2. 附件图片依赖飞书返回的临时链接；若链接过期/无权限，图片处显示文件名占位。
3. 打印前务必在浏览器打印设置中将"边距"设为"无"、缩放 100%。
4. 数据安全：条码/二维码/图片解析全部在浏览器本地完成，不向外部发送多维表格数据。
